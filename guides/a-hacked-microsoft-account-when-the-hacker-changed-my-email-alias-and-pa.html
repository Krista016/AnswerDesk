How do I recover a hacked Microsoft Account when the hacker changed my email alias and password?

Written & Audited by Emily Watson Microsoft Systems & Exchange Expert • AnswerDesk Vetted Expert • Updated November 2026
⚡ Quick Expert Answer • Microsoft Account, Authenticator, Microsoft Store, Surface, Edge & Xbox

Go immediately to account.live.com/acsr (Microsoft Account Recovery Form) from a previously trusted device and home IP address. Provide old passwords, Xbox Gamertag, Skype ID, billing card last 4 digits, and recent Outlook email subjects. If the primary alias was deleted and replaced, contact Microsoft Support via the Account Compromise guided flow to lock the account while ownership is audited.

Before You Start: Quick Pre-Check

  • ✓Sign in with a Windows Administrator account so elevated Command Prompt, PowerShell, and Settings changes apply cleanly.
  • ✓Save open documents and create a quick System Restore point before editing services, drivers, or registry keys.
  • ✓Note the exact hexadecimal error code (e.g., 0x800xxxxx) or Event Viewer timestamp if the error repeats.

How to Verify the Fix Worked

  1. Restart Windows fully (Start > Power > Restart — not Shut Down, which uses Fast Startup caching) and confirm the error no longer appears.
  2. Open Windows Update or Event Viewer (Windows Logs > System / Application) and verify there are no fresh red critical errors for the affected component.
  3. Confirm dependent apps, drivers, or Microsoft 365 services sign in and sync normally without prompts.

What if the issue still persists? If the same stop code or error persists after DISM/SFC repair and a full reboot, boot into Safe Mode with Networking or test under a new local Windows user profile to isolate profile corruption vs. failing storage/RAM hardware.

Frequently Asked Questions

Will fixing "recover a hacked Microsoft Account when the hacker changed my email alias and password" delete my personal files, data, or account history?

Standard Windows diagnostic fixes (DISM, SFC, cache resets, and service restarts) repair operating system files without deleting personal Documents, Desktop files, or photos. Only avoid selecting "Remove everything" during a Windows Reset unless you have an external backup.

How long does it normally take to resolve this Microsoft & Windows issue?

Most Windows service, network, and Microsoft 365 cache repairs take 5–15 minutes. Full DISM/SFC image scans or an in-place Windows repair upgrade typically take 20–45 minutes depending on SSD speed and download bandwidth.
