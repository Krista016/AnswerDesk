How do I fix Windows Security Intelligence Update failing with Error 0x80070643 or 0x80240022?

Written & Audited by Daniel Cooper Windows Kernel Security & Threat Analyst • AnswerDesk Vetted Expert • Updated November 2026
⚡ Quick Expert Answer • Core Service & Error Codes

Definition update errors occur when SoftwareDistribution metadata corrupts or Defender's MpCmdRun.exe cache breaks. Open Command Prompt as Administrator and run "%ProgramFiles%\Windows Defender\MpCmdRun.exe" -removedefinitions -dynamicsignatures followed by "%ProgramFiles%\Windows Defender\MpCmdRun.exe" -SignatureUpdate—or download the standalone mpam-fe.exe offline definition package directly from Microsoft.

Before You Start: Quick Pre-Check

  • ✓Verify whether a third-party antivirus (Norton, McAfee, Avast, Bitdefender, etc.) is installed, because Windows automatically puts Microsoft Defender into passive/off mode when another AV registers.
  • ✓Open PowerShell or Command Prompt using "Run as Administrator" before executing Defender service or MpCmdRun commands.
  • ✓Check Windows Settings > Accounts > Access work or school to verify whether a school/company Intune or Group Policy profile is managing security settings.

Why This Issue Happens

Definition update errors occur when SoftwareDistribution metadata corrupts or Defender's MpCmdRun.exe cache breaks.

This issue falls under Core Service & Error Codes (Windows Defender & Security). Confirming the exact trigger before making changes prevents unnecessary resets and helps preserve your data and account standing.

Step-by-Step Resolution Protocol

Step 1
Primary Resolution Step

Open Command Prompt as Administrator and run "%ProgramFiles%\Windows Defender\MpCmdRun.exe".

"%ProgramFiles%\Windows Defender\MpCmdRun.exe" -removedefinitions -dynamicsignatures
"%ProgramFiles%\Windows Defender\MpCmdRun.exe" -SignatureUpdate
Step 2
Action Step 2

-removedefinitions -dynamicsignatures followed by "%ProgramFiles%\Windows Defender\MpCmdRun.exe".

Step 3
Secondary Recovery & Fallback

-SignatureUpdate—or download the standalone mpam-fe.exe offline definition package directly from Microsoft.

How to Verify the Fix Worked

  1. Open PowerShell as Administrator and run Get-MpComputerStatus to verify AMServiceEnabled, AntivirusEnabled, RealTimeProtectionEnabled, and BehaviorMonitorEnabled all return True.
  2. Open Windows Security (windowsdefender:) and confirm Virus & Threat Protection, Firewall & Network Protection, and Device Security all show green checkmarks with current definition dates.
  3. Run a Quick Scan or verify Protection History to confirm the prior error code or repeated alert has cleared.

What if the issue still persists? If WinDefend or SecurityHealthService still fails to start with error 577, 0x80070422, or blank UI screens after removing legacy AV drivers and running DISM/SFC, perform an in-place Windows 11/10 Repair Upgrade (keeping all files and apps) to restore signed Defender binaries.

⚠️ Expert Safety & Verification Advisory: Never permanently disable Real-Time Protection, Tamper Protection, or exclude the entire C:\ drive to silence alerts—doing so leaves your PC exposed to ransomware and infostealers. Verify your BitLocker Recovery Key is backed up before changing TPM or Core Isolation settings.

Frequently Asked Questions

Will fixing "Windows Security Intelligence Update failing with Error 0x80070643 or 0x80240022" delete my personal files, data, or account history?

Resetting Windows Security, updating Defender signatures, running Microsoft Defender Offline Scan, or re-enabling WinDefend/MpsSvc services will not delete your personal files. Legitimate files flagged as false positives can be restored safely from Protection History.

How long does it normally take to resolve this Windows Defender & Security issue?

Service restarts, signature updates, and PowerShell resets take 2–5 minutes. A Microsoft Defender Offline Scan takes 10–15 minutes during reboot, while a full disk scan takes 30–90 minutes depending on drive size.

What should I do if the problem returns after following these steps?

If WinDefend or SecurityHealthService still fails to start with error 577, 0x80070422, or blank UI screens after removing legacy AV drivers and running DISM/SFC, perform an in-place Windows 11/10 Repair Upgrade (keeping all files and apps) to restore signed Defender binaries.
