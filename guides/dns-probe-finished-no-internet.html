DNS_PROBE_FINISHED_NO_INTERNET in Google Chrome / Edge Resolution

Written & Audited by Alex Rivera Network Infrastructure Engineer (CCNA) • AnswerDesk Vetted Expert • Updated November 2026
⚡ Quick Expert Answer • Smart Home & Networking

Flush local Windows DNS resolver cache, reset Winsock catalog, and change adapter IPv4 DNS.

Pre-Fix Diagnostic Checklist

  • ✓Flush DNS resolver cache via ipconfig /flushdns
  • ✓Change IPv4 DNS to 1.1.1.1 and 1.0.0.1
  • ✓Disable Secure DNS (DoH) temporarily in Chrome settings
  • ✓Write down the exact error message, flashing LED pattern, or fault code displayed before restarting the device.

Diagnostic & Troubleshooting Protocol

Flush local Windows DNS resolver cache, reset Winsock catalog, and change adapter IPv4 DNS.

Step 1
Flush and Register DNS via Terminal

Purges poisoned or corrupted local DNS domain cache records.

ipconfig /flushdns
ipconfig /registerdns
netsh winsock reset
Step 2
Disable Chrome Secure DNS Flag

Prevents DNS-over-HTTPS fallback timeouts on restrictive enterprise networks.

Chrome Settings > Privacy & Security > Security > Use Secure DNS > Turn OFF
Step 3
Clear Local Host File Hijacks

Verify malicious entries aren't redirecting DNS lookups to local loopback addresses.

Inspect C:\Windows\System32\drivers\etc\hosts
Expert Caution / Safety Note: Third-party browser antivirus plugins often hijack DNS requests; test in Chrome Incognito mode with extensions disabled.
